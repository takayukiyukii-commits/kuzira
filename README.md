## なぜ作ったか

競合のLPを1本分析するだけで、実際にはこれだけの作業が発生します。

> ページを開く → スクショを撮る → どこに保存したか忘れる → 計測タグを見るために開発者ツールを開く →
> 見出し構造をコピペする → ChatGPTに貼って分析させる → 結果をNotionに書く → 1週間後、何を見たか思い出せない

KUZIRAは、この一連を**ブラウザの中に最初から入れて**しまいました。
ページを開いた時点で解析は終わっていて、`Ctrl+D` で丸ごと保存され、そのままAIに聞けます。

**想定ユーザー**：広告運用者／LP制作者／SNS運用者／個人でサービスを作って売る人

## できること

### 1. 魚拓（フルページ保存）とスワイプファイル

`Ctrl+D` を押すと、表示中のページを**縦に全部つなげた1枚のPNG**として保存します。スクロールも分割スクショも不要です。

保存されるのは画像だけではありません。

- フルページのスクリーンショット（＋一覧用サムネイル）
- ページ本文のテキスト
- タイトル・URL・保存日時
- 検出した計測タグの一覧

保存したページは**スワイプファイル**（`Ctrl+Shift+S`）にカード表示され、タイトル・URL・タグで横断検索できます。
「あの時見たLP」を、記憶ではなく検索で引き出せます。

> 魚拓はご自身のリサーチ用です。第三者への公開・配布や、文章・デザインの転用はお控えください。

---

### 2. AIリサーチ（Claude Code / Codex / Gemini をそのまま使う）

サイドバーからページについてAIに直接質問できます。ワンクリックの定型質問も用意しています。

- 「このページのマーケティング的に上手い点を3つ」
- 「改善点を3つ、優先度順に」
- 「訴求軸と想定ターゲットを分析して」
- **「自社ナレッジを踏まえて、盗める点と差別化案を教えて」**

**APIキーがなくても動きます。** PCに入っている以下のCLIを自動検出して、そのまま使います。

| 接続方法 | 必要なもの |
|---|---|
| Claude Code（CLI） | `claude` コマンド |
| Codex（CLI） | `codex` コマンド |
| Gemini（CLI） | `gemini` コマンド |
| OpenAI APIキー | キーを設定画面に貼るだけ |
| Gemini APIキー | キーを設定画面に貼るだけ |

**自社ナレッジの読み込み**：商品情報・ターゲット・強みを書いた `.md` / `.txt` の入ったフォルダを指定すると、AIがそれを前提知識として分析します。「一般論のアドバイス」ではなく「自社ならどう使うか」が返ってきます。

**関連機能**
- **構造マーキング** … H1（水色）とCTA（緑）をページ上に枠線で可視化
- **AI要点マーキング** … AIが重要箇所を抽出してページに直接マーキング
- **PDF / Word 書き出し** … 表示中のページをそのまま保存
- **分析ノート** … AI分析の結果はMarkdownで自動保存（Obsidian互換）

---

### 3. 計測タグ・ページ構造の自動解析

ページを開くと、右サイドバーに**自動で**表示されます。開発者ツールは不要です。

- **検出タグ・ピクセル** … GA4 / Google広告 / Meta Pixel / TikTok Pixel / LINEタグ / Microsoft Clarity / Hotjar など
- **ページ構造** … CTA数・H2見出し数・画像数・文字量
- **H1（メイン訴求）・meta description・CTA文言**

「この競合は何で計測していて、どんな訴求で、どこにCTAを置いているか」が、開いた瞬間に分かります。

---

### 4. 競合ウォッチ（毎日の自動巡回＋変化のAI要約）

目のアイコンから競合ページを登録すると、**KUZIRAが自動で巡回して変化を検知**します。

- 巡回はバックグラウンドで自動実行（前回から20時間以上経過したものが対象）
- 変化があったページは**AIが「何がどう変わったか」を要約**
- 未読はバッジで通知。ダッシュボードに時系列で溜まります

価格改定・訴求変更・新機能の追加を、毎日手で見に行かずに追えます。

---

### 5. スプリットビューとAI比較分析

現在のタブと直前のタブを**左右に並べて表示**します。そのまま「比較分析」を押すと、AIが2ページを比較して、訴求・構成・CTAの違いをレポートします。

自社LPと競合LPを並べて、どこで負けているかを言語化するのに使います。

---

### 6. プロファイル完全分離（自社／競合／ペルソナ）

ツールバーのドロップダウンで、Cookie・ストレージが**完全に分離**された3つのプロファイルを切り替えられます。

| プロファイル | 用途 |
|---|---|
| 🔵 自社運用 | 自社アカウントでの管理画面作業 |
| 🔴 競合調査 | ログアウト状態での競合閲覧・広告の出方確認 |
| 🟠 ペルソナA | 見込み客の視点でのリターゲティング広告確認 |

同じサイトに**別アカウントで同時ログイン**できます。シークレットウィンドウを開いたり、ログアウトし直す必要はありません。

**広告ブロック**（uBlock系フィルタ）もプロファイルごとにON/OFFできます。自社運用ではONで快適に、競合調査では**OFFにして「どんな広告が出ているか」まで観察**する、といった使い分けができます。

---

### 7. タブグループ・タブ管理

リサーチ中はタブが増えます。Chrome同様の**タブグループ**で案件別にまとめられます。

- タブを**右クリック ▸ グループ**で作成／既存グループへ追加／グループから外す
- **ドラッグ＆ドロップ**でグループへ出し入れ
- グループ名のチップを**クリックで折りたたみ／展開**、**右クリックで名前変更・色（8色）・一括クローズ**
- グループ内のタブは自動でコンパクト表示になり、**見ているタブだけタイトルが開く**
- **終了しても復元**（開いていたタブ・グループ名・色・折りたたみ状態を保存）

その他：タブの固定、サイトのミュート、タブの複製、右側のタブを閉じる、中クリックで閉じる、といった基本操作も一通り揃っています。

---

### 8. マーケツール（UTM／QR／OGP）

「そのためだけに別サイトを開く」小道具を内蔵しています。

- **UTMビルダー** … source / medium / campaign / content を入れて計測用URLを生成、そのままコピー or 開く
- **QRコード生成** … URLやテキストからQRを生成してPNG保存
- **OGPチェッカー** … 表示中のページのOGP画像・タイトル・説明文を確認（SNSでどう見えるか）

---

### 9. ダッシュボード（GA4・UNIシリーズKPI）

競合ウォッチの変化イベント・分析ノート・最近の魚拓を1画面に集約。
**GA4のサービスアカウント**を設定すると、自社サイトのアクセス指標もここに並びます。
[UNIシリーズ](https://zuboland.jp)をお使いの場合は、各製品のKPIも同じ画面に統合表示できます。

---

### 10. AIエージェント代行（MCPサーバー内蔵・27ツール）

KUZIRAは**MCPサーバー**（`http://127.0.0.1:8377/mcp`）を内蔵しています。
Claude Code や Codex から接続すると、**AIがあなたのブラウザをそのまま操作**できます。

ログイン済みのセッションをそのまま使えるので、「AIに調べさせたいけどログインが必要」という壁がありません。

<details>
<summary><b>提供している27ツール</b></summary>

| 分類 | ツール |
|---|---|
| タブ操作 | `list_tabs` `open_tab` `navigate` `activate_tab` `close_tab` |
| ページ読取 | `read_page` `snapshot` `screenshot` |
| 操作 | `click` `click_at` `type_text` `press_key` `scroll` `select_option` `upload_file` `wait_for` |
| 調査・デバッグ | `read_console` `read_network` `wait_download` `run_js` |
| 録画 | `start_recording` `stop_recording` |
| 二段階認証 | `totp_save` `totp_code` `totp_list` |
| セッション | `export_cookies` `import_cookies` |

</details>

**安全側の設計**

- 既定では操作のたびに**承認ダイアログ**が出ます（60秒無応答で自動拒否）
- 「エージェントモード」をONにすると自動許可になりますが、**全操作が監査ログとスクリーンショットで記録**されます
- **操作拒否リスト**にドメインを書いておくと、そのページはAIが操作できません（ネットバンキング等）
- **裏タブ**での作業に対応。AIが調べ物をしている間も、あなたの画面は占有されません

## データはどこに保存されるか

**すべてあなたのPCの中だけです。** KUZIRAはリサーチ内容を外部サーバーへ送信しません。

| データ | 保存先 |
|---|---|
| 魚拓（画像・テキスト） | ユーザーデータフォルダ内 `swipefile/`（アプリから「フォルダを開く」で辿れます） |
| 分析ノート | Markdown（Obsidian互換） |
| 設定・APIキー | ローカルの設定ファイル（このPCにのみ保存） |
| Cookie・ログイン状態 | プロファイルごとに分離して保存 |

AIに質問した時だけ、そのページの内容が**あなたが選んだAI**（ローカルのCLI、または設定したAPIキーの接続先）に送信されます。
