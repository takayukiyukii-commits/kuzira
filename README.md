## Claude Code スキル（無料配布）

KUZIRA を「AIの目と手足」として使うためのスキルを配布しています。
Claude Code にコピーするだけで `/コマンド` として能力が増えます。

| スキル | できること |
|---|---|
| **x-pulse** | 広告や発信の訴求軸を、推測ではなく **X上の実測エンゲージメント**で決める。訴求案・ターゲティング用キーワードまで出力し、調査を魚拓＋Obsidian互換ノートで資産化 |
